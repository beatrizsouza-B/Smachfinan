# 💰 FinanSmart AI — Inteligência Financeira

## 🚀 Sobre o projeto

O **FinanSmart AI** é um projeto de tecnologia voltado à organização e ao planejamento financeiro pessoal, com uma proposta moderna que combina gestão financeira, inteligência artificial e experiência digital.

A plataforma tem como objetivo ajudar usuários a controlar seus gastos, acompanhar receitas, organizar seu orçamento e tomar decisões financeiras mais inteligentes.

## 🎯 Objetivo do projeto

Desenvolver uma solução digital intuitiva e inteligente que facilite o controle financeiro, incentive hábitos saudáveis com o dinheiro e ajude as pessoas a conquistarem maior independência financeira.

## ✨ Funcionalidades

- 📊 Dashboard financeiro interativo.
- 💵 Controle de receitas e despesas.
- 📉 Acompanhamento de gastos.
- 🎯 Planejamento de metas financeiras.
- 📅 Organização do orçamento mensal.
- 🤖 Proposta de assistente financeiro com inteligência artificial.
- 📈 Visualização de indicadores financeiros.
- 📱 Interface responsiva para dispositivos móveis e computadores.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** design, estilização e responsividade.
- **JavaScript:** interatividade e funcionalidades.

## 🎨 Design e experiência do usuário

O FinanSmart AI apresenta uma proposta visual moderna, tecnológica e intuitiva, com foco na facilidade de navegação, organização das informações e visualização dos dados financeiros.

## 📱 Responsividade

A interface foi planejada para oferecer uma experiência adaptável a diferentes dispositivos, incluindo:

- Computadores.
- Tablets.
- Smartphones.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra no navegador ou utilize a extensão Live Server.

## 🌟 Diferencial do projeto

O diferencial do FinanSmart AI é unir organização financeira e tecnologia em uma experiência simples e acessível, com potencial para evoluir e incorporar recursos de inteligência artificial para auxiliar no planejamento financeiro.
